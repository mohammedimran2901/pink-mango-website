## Description
Health management is an executive function task — which makes it doubly hard for AuDHD women. This book covers sleep, food, movement, hormones, medication, and medical appointments, built around systems that work for the AuDHD brain instead of guilt. Book 3 of the AuDHD Fix trilogy.
